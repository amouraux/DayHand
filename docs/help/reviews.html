DayHand Help · Reviewing your work

A little time to reconsider

Open More → Review and choose a helper. The aim is to make decisions about your work, one task or project at a time.

Choose a task review

Review Inbox
Where does this belong? Move new tasks into the stack that matches your intention, or leave them in Inbox if you are not ready.
Review Now
Am I still working on this? Keep active work, move what has changed, or complete what is finished.
Review Waiting
Can this move forward? Keep genuinely blocked work here, bring it back to Now or Next, or set a reminder to follow up.
Review Next and Later
Is this still relevant? Bring forward what matters and reconsider what you are keeping for the future.
Review all tasks
Work through Inbox, Now, Waiting, then Next and Later in one pass. Moving a task does not make it appear again later in that same pass.

Use the familiar task actions

The helper shows the task’s details and how long it has been in its stack. Keep it where it is, move it, edit it, complete it or delete it as appropriate. The stack buttons keep their positions so you can use them consistently on a phone.

You can leave a review and return to it. Progress is saved on that device; it does not follow you to another device. New arrivals normally wait for a new pass.

Reviewing is a decision, not a deadline. Keeping a task in Now is a valid outcome, even if it has been there for a while.

Review projects

Choose Review projects to consider the question: “Does this project have a clear way forward?” The overview groups its tasks by stack and shows its category and group.

  • Looks right — next project: accept the overview and continue.
  • Add a task: capture a missing step with the project already selected.
  • Review these tasks: work through this project’s tasks using the task helper.
  • Edit project: change the project’s details.

Adding, editing or reviewing tasks returns you to the same project overview. Use the back chevron to revisit the previous project and the cross to leave the review.

Projects with unfinished work come first, followed by projects with no work left so you can archive them. Archived projects are excluded. Tasks without a project remain available in the task reviews. Task decisions are shared within a project-review pass to avoid repeats after reassignment.

Archiving a project that still has unfinished tasks requires confirmation to complete and archive them. It is not a way to pause unfinished work.

Look back at completed work

More → Timeline and a project’s History show what you have completed. These are separate from the helpers, which help you decide what to do with open work.

Help checked against the app on 31 October 2026. Labels may differ in older builds or other languages.
