Help · Reviewing your work

Reviews

Open More → Review and pick a helper. Each one asks a single question about a single task or project, so you decide instead of scanning a long list.

Reviewing tasks

Review Inbox
Where does this belong? Move new tasks to the stack that fits, or leave them if you are not ready.
Review Now
Am I still working on this? Keep what is active, move what has changed, complete what is done.
Review Waiting
Can this move forward? Keep what is really blocked, bring back what is not, or set a reminder to chase.
Review Next and Later
Is this still relevant? Bring forward what matters and let go of what does not.
Review all tasks
Inbox, Now, Waiting, then Next and Later, in one pass. A task you move during the pass does not come back later in the same pass.

The helper shows the task, and how long it has been in its stack. Keep it where it is, move it, edit it, complete it or delete it. The stack buttons stay in the same place from one task to the next, so your thumb learns them.

You can stop in the middle and come back. Your place is saved on that device only; another device starts its own pass. Tasks that arrive in the meantime wait for the next pass.

A review is a decision, not a deadline. “Keep in Now” is a perfectly good answer, even for a task that has been there a month.

Reviewing projects

Review projects asks one question for each project: does it have a clear way forward? You see its tasks by stack, with its category and group.

  • Looks right — next project: fine, move on.
  • Add a task: write down the missing step, with this project already selected.
  • Review these tasks: go through this project’s tasks one at a time.
  • Edit project: change its name, category or group.

After adding, editing or reviewing you come back to the same project. The chevron at the top left goes back to the project you just left, and the cross leaves the review.

Projects with unfinished work come first. Projects with nothing left to do come after, so you can archive them. Archived projects are skipped, and tasks without a project show up in the task reviews instead.

Archiving a project that still has open tasks asks you to complete them first. Archiving is for finished work, not a way to put a project to sleep; for that, use Later.

Looking back

More → Timeline, and the History of a single project, show what you have finished. They are separate from the helpers, which are about the work still open.
