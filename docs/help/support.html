DayHand Help · Support

Let’s get you moving again

Check the common questions below, or send a report so we can understand what happened.

I cannot find my tasks

Clear search, category/project filters and the flag filter. Check the other stacks and Timeline. If a second device has different tasks, check sync setup before replacing or restoring anything.

If you moved from an older self-built Mac app to TestFlight, the app may use a different data location. If you previously used an iCloud sync file, connect to that same file again using Use Existing Sync File… and review the merge choice.

A reminder did not notify me

  • Check that notifications are allowed for DayHand in your device’s system settings, and whether Focus or notification delivery settings are silencing them.
  • New reminders normally fire at 9 a.m. Setting today’s reminder after that time does not schedule another notification today.
  • A completed task or a cleared reminder will not notify. A reminder already answered for that day need not notify again.
  • Open DayHand to let it refresh its local schedule, especially after changes on another device.

The in-app flag and app icon badge measure different things. See colours and counts if they disagree.

My imported tasks look different

Each importer has limits for dates, recurring tasks and extra details. Read the import guide and check Notes for information retained as text. Imports do not keep changes in sync with the original app.

Report a bug or ask for help

During the beta, use Send Beta Feedback in TestFlight. You can also open an issue on GitHub for a question, bug or feature request. Posting there requires a GitHub account; reading this help does not.

Please include:

  • Your device, operating-system version, and DayHand version/build.
  • What you tried, what you expected, and what happened instead.
  • Steps that reproduce the problem and the exact error message, if any.
  • For sync problems, which devices are affected and the sync status on each.
GitHub issues are public. Remove private task titles from screenshots. Do not attach your task file, backup, account credentials or personal information to a public report. Describe the issue with a small invented example where possible.

Browse existing reports to see whether the issue has already been raised.

Help checked against the app on 31 October 2026. Labels may differ in older builds or other languages.
