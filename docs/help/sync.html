DayHand Help · Sync across devices

One file, all your devices

DayHand uses a file in your own iCloud Drive to share tasks between devices. No DayHand account is needed. On a single device, you can use the app without setting up sync.

Connect the first device

  1. Make sure iCloud Drive is available on the device.
  2. Open More → Sync → Create Sync File….
  3. Save the file in an iCloud Drive folder you can find again.
  4. Allow iCloud to upload the file before connecting another device.

Connect each additional device

  1. Use the same Apple Account for iCloud Drive and make sure the file is downloaded.
  2. In DayHand, open More → Sync → Use Existing Sync File….
  3. Choose Merge With This Device to retain the tasks on both sides.
  4. Select the same file created on the first device. Do not create another file with the same name.
  5. Check your tasks and the sync status on both devices.
Replacing is different: “Replace Tasks on This Device” discards this device’s current task list and adopts the selected file’s tasks. Make a backup first if you need the current list.

Everyday use

DayHand keeps a local copy, so you can work offline. Changes merge when the shared file becomes available and the app reads it. iCloud delivery can take time; sync is not a promise of instant updates on a closed app.

Avoid editing the same task on two devices while both are offline. When versions of a task conflict, one version wins; the app does not combine individual edits to its text.

If devices disagree

  1. Check More → Sync on each device. “Not syncing” means no file is linked there.
  2. Confirm both devices use the same file and location. Matching filenames alone are not enough.
  3. Check iCloud Drive connectivity and download status in Files or Finder.
  4. Open DayHand on both devices and choose Sync Now. Read the result below the button.
  5. If access was lost after moving the file, back up your current tasks, stop using the old link and select the intended file again. Use Merge to retain both sets.

DayHand checks that a selected sync file is a DayHand document. Do not select a spreadsheet, unrelated JSON file or a blank file.

Disconnect or recover a copy

Stop Using This File disconnects this device; its local tasks remain. If you want to read a saved copy once without linking it for sync, use Restore From File… instead.

Still stuck? Send a support report with the sync status shown on each device.
