Help · Sync across devices

Sync

DayHand shares your tasks through one file in your own iCloud Drive. There is no DayHand account and no server. On a single device you do not need any of this.

The first device

  1. Make sure iCloud Drive is on.
  2. Open More → Sync → Create Sync File….
  3. Save the file in an iCloud Drive folder you will find again.
  4. Give iCloud a moment to upload it before you set up the next device.

Every other device

  1. Sign in with the same Apple Account, and make sure the file has downloaded.
  2. Open More → Sync → Use Existing Sync File….
  3. Choose Merge With This Device, which keeps the tasks on both sides.
  4. Pick the same file you created on the first device. Do not create a second file with the same name; two files with one name are two different files.
  5. Look at your tasks and at the sync status on both devices.
Replace is a different thing. “Replace Tasks on This Device” throws away what is on this device and takes the file’s tasks instead. If you might want the current list back, make a backup first.

DayHand checks that the file you pick really is a DayHand file. A spreadsheet, somebody else’s JSON or a photo is refused, because syncing writes into the file and would overwrite it.

Day to day

Each device keeps its own copy, so you can work offline. Changes meet through the file once iCloud has delivered it and DayHand has read it. That can take a while, and an app that is closed does not hurry. Do not expect it to be instant.

Avoid editing the same task on two devices while both are offline. If two versions of one task conflict, the most recent edit wins. DayHand does not stitch two edits of the same title together.

When the devices disagree

  1. Look at More → Sync on each device. “Not syncing” means no file is linked there.
  2. Check that both use the same file in the same place. The same name is not enough.
  3. Check that iCloud Drive is connected and that the file has finished downloading, in Files or in Finder.
  4. Open DayHand on both devices and tap Sync Now. Read the line under the button.
  5. If you moved or renamed the file and a device lost it, back up that device, stop using the old link, and pick the right file again, choosing Merge.

Disconnecting

Stop Using This File disconnects this device. Its tasks stay. If you only want to look at a saved copy once, without linking anything, use Restore From File… instead.
