DayHand Help · Imports and backups

Your tasks stay yours

Bring tasks into DayHand, export a copy, or recover saved work. Imports are one-time copies; they do not keep the original app connected.

Import from Apple Reminders

  1. Open More → Tasks → Import from Apple Reminders….
  2. Allow Reminders access. Apple requires full access to read the lists; DayHand only reads them and does not change them.
  3. Select lists, choose the destination stack and project/category options, and decide whether to import due dates.
  4. Review the preview and confirm the import.

Due dates become DayHand reminders at 9 a.m., not deadlines. Original dates and times are retained in Notes. Recurring reminders are skipped. Subtask structure, tags, attachments and smart-list rules are not preserved; notes, links, locations and priority values are retained as text where available.

A backup is saved before import. Repeating an import on the same device skips items already imported, including ones you deleted. Importing on another device or after an account reset can produce duplicates.

Import from Todoist

  1. Export your Todoist projects as CSV files.
  2. Open More → Tasks → Import from Todoist… and select one or more exported CSV files.
  3. Choose the destination stack, project and category for each file, and review date options.
  4. Check the preview and warnings, then choose Import.

Todoist project CSV exports do not contain completed tasks. Recognised task dates become reminders at 9 a.m.; recognised deadlines stay deadlines. Descriptions, exported comments and other supported details are kept in Notes. Subtasks become separate tasks, with their parent and section context in Notes; attachments are not downloaded. Recurring schedules are not recreated, and unrecognised dates need review; choosing to include those tasks keeps the unrecognised date text in Notes.

A backup is saved first. Reimporting an unchanged file with the same name skips previously imported rows. Editing or renaming the export can create duplicates.

Check your alerts: Apple Reminders and Todoist keep their own notifications. Imported future reminders can also notify you in DayHand. Decide where you want to receive alerts.

DayHand CSV import and export

Use More → Tasks → Export as CSV… to save a portable copy. Use Import from CSV… → Add to Existing Tasks to merge a DayHand CSV with your work. Replace All Tasks removes the current tasks first; review that choice carefully.

Use the dedicated Todoist importer for Todoist exports. CSV formats from other apps are not automatically interchangeable. Export a DayHand sample to see its format before preparing your own file.

Keep a backup

Under More → Backups, choose Back Up Now before a major change. Automatic backups are taken on days the app opens, in rotating slots. They are not a permanent archive; a second manual backup on the same day replaces that day’s manual copy.

Use a backup’s Share action to keep a separate copy in a location you choose. On Mac, right-click a backup for Restore, Share and Delete; on iPhone or iPad, press and hold. Swipe actions are also available.

Restore saved work

  1. Back up or export the current tasks if you may need them again.
  2. Choose a listed backup to restore, or choose Restore From File… and select a DayHand file.
  3. Read the task counts in the confirmation. Restoring replaces current tasks and restores categories and projects too.
  4. Confirm only when this is the copy you want.

Restore From File only reads the selected file. It does not link that file for future sync. Your existing sync connection remains in place, so restored changes can reach other connected devices. If you want to inspect a copy in isolation, disconnect sync first.

For an ongoing connection to a shared file, follow Set up sync instead.
