Informativa sulla privacy

Le tue attività restano nei tuoi file. DayHand non invia il contenuto delle tue attività allo sviluppatore e non gestisce alcun server che le conservi.

Panoramica

Questa informativa riguarda DayHand per iPhone, iPad e Mac e spiega separatamente come vengono trattate le informazioni che scegli di condividere tramite l’assistenza o questo sito web.

L’app non ha un account DayHand, pubblicità, tracciamento né SDK di analisi di terze parti. Lo sviluppatore non riceve le tue liste di attività, le note o i promemoria importati durante il normale utilizzo dell’app. DayHand non vende le tue informazioni personali e non le usa per la pubblicità.

Attività, impostazioni e backup

Attività, note, progetti, categorie, gruppi, date e informazioni di completamento sono memorizzati in un documento DayHand sul tuo dispositivo. L’app memorizza in locale anche le impostazioni e l’avanzamento delle revisioni. Queste informazioni servono a offrire la gestione delle attività, la ricerca, le revisioni e il ripristino.

DayHand crea backup locali e ti consente di fare e condividere copie aggiuntive. Backup ed esportazioni possono contenere le stesse informazioni private della tua lista di attività. I loro nomi di file possono includere il nome di un dispositivo. Restano nei luoghi in cui tu o l’app li avete salvati; non vengono caricati sul server dello sviluppatore.

I documenti DayHand e le esportazioni CSV sono file leggibili; l’app non aggiunge una propria protezione con password né la cifratura. L’accesso dipende dalla sicurezza del tuo dispositivo, dai permessi dei file e dal servizio di archiviazione che scegli.

Sincronizzazione tramite il tuo iCloud Drive

Se attivi la sincronizzazione, DayHand legge e scrive il file che selezioni nel tuo iCloud Drive. Apple trasferisce quel file tra i tuoi dispositivi con il tuo account iCloud. Il file non passa da alcun server DayHand e attivare la sincronizzazione non dà accesso allo sviluppatore.

Il trattamento dei dati iCloud da parte di Apple è regolato dall’informativa sulla privacy di Apple e dalle impostazioni del tuo account. Se metti un file in una cartella condivisa o condividi una copia con qualcuno, quella persona potrebbe poterne leggere il contenuto.

Importare le attività

L’importazione da Promemoria di Apple richiede l’accesso per leggere le tue liste. DayHand usa questa autorizzazione per copiare i promemoria che selezioni e non modifica gli originali. I contenuti importati, comprese le note supportate e altri dettagli, diventano parte dei tuoi file DayHand.

Le importazioni CSV di Todoist e di DayHand leggono file che selezioni sul tuo dispositivo. DayHand non chiede la tua password di Todoist e non si collega al tuo account Todoist. Queste importazioni sono copie una tantum, non collegamenti continui con il servizio originale.

Promemoria e notifiche

DayHand pianifica notifiche locali tramite il sistema operativo di Apple. Il contenuto di una notifica può includere il titolo di un’attività, che può comparire sulla schermata di blocco a seconda delle tue impostazioni delle notifiche. DayHand non invia titoli di attività a un server di notifiche gestito dallo sviluppatore.

Servizi Apple e acquisti

Apple gestisce i download dall’App Store, la distribuzione tramite TestFlight e le informazioni diagnostiche che scegli di condividere dalle impostazioni di Apple. Apple può rendere disponibili allo sviluppatore report diagnostici o feedback della beta. DayHand non include alcun servizio aggiuntivo di analisi o di segnalazione degli arresti anomali.

L’attuale beta non offre ancora i flussi previsti di acquisto, prova e ripristino degli acquisti. Quando saranno disponibili, gli acquisti saranno elaborati da Apple e DayHand userà le informazioni di acquisto di StoreKit per stabilire l’accesso sul dispositivo. Lo sviluppatore non riceverà i dati della tua carta di pagamento tramite l’app. Questa informativa sarà aggiornata se cambia il modo in cui vengono trattati i dati di acquisto.

Le tue scelte sulla privacy e l’eliminazione dei dati

  • Usa DayHand solo in locale: la sincronizzazione non è obbligatoria. Per scollegare un file collegato, scegli Altro → Sincronizzazione → Smetti di usare questo file. Le tue attività locali restano e il file condiviso non viene eliminato.
  • Revoca l’accesso a Promemoria: modifica l’autorizzazione di DayHand per Promemoria nelle impostazioni di sistema del tuo dispositivo. Revocare l’autorizzazione non rimuove le attività già importate; eliminale a parte se non le vuoi più.
  • Controlla le notifiche: disattivale o nascondi le anteprime nelle impostazioni di sistema. In DayHand puoi anche cancellare i promemoria delle singole attività.
  • Esporta il tuo lavoro: usa Altro → Attività → Esporta in CSV, oppure condividi un backup da Altro → Backup.
  • Elimina le attività: eliminale nell’app. Con la sincronizzazione attiva, le eliminazioni possono propagarsi ai dispositivi collegati. I backup meno recenti e le copie esportate possono contenere ancora il contenuto eliminato.
  • Rimuovi le copie salvate: elimina i backup da Altro → Backup ed elimina in File o nel Finder le esportazioni o i file condivisi che non ti servono più. Controlla anche gli altri dispositivi e le funzioni «eliminati di recente» o di recupero del tuo servizio di archiviazione.

I dati delle attività attive vengono conservati finché non li modifichi o li elimini. I backup automatici ruotano; i backup manuali e le copie che condividi restano finché non vengono sostituiti o eliminati. I registri di eliminazione usati per la sincronizzazione possono conservare identificativi delle attività e date di eliminazione, ma non il contenuto delle attività. Rimuovere l’app non elimina i file iCloud salvati a parte, le esportazioni né le copie su altri dispositivi.

Non c’è alcun account DayHand da chiudere. Lo sviluppatore non può recuperare né cancellare da remoto i file di attività che restano solo sui tuoi dispositivi o nel tuo account di archiviazione.

Le informazioni che invii e come contattarci

Per domande su questa informativa o per una richiesta sulla privacy, contatta lo sviluppatore di DayHand tramite la pagina di assistenza. È disponibile anche GitHub Issues per domande generali e segnalazioni di errori.

Se invii un feedback, un report diagnostico o un messaggio di assistenza, lo sviluppatore riceve le informazioni che includi e quelle fornite dal canale usato, come un indirizzo di contatto, dettagli sul dispositivo o allegati. Queste informazioni servono per rispondere, risolvere i problemi e migliorare DayHand. I dati dell’assistenza possono essere conservati per il tempo necessario a risolvere la richiesta e a seguirne gli sviluppi; per chiedere l’eliminazione delle informazioni che hai fornito, contatta lo sviluppatore attraverso lo stesso canale. Apple e GitHub gestiscono le proprie copie e la loro conservazione secondo le proprie politiche.

Le segnalazioni su GitHub sono pubbliche. Non pubblicarvi attività private, backup, credenziali o dati personali. Usa un esempio inventato quando possibile. Per una richiesta sulla privacy, inizia senza dettagli sensibili e chiedi un modo adeguato per proseguire.

Questo sito web e i servizi esterni

Questo sito web è ospitato su GitHub Pages. Non aggiunge script di analisi né cookie pubblicitari. GitHub può trattare informazioni di connessione, come indirizzi IP e registri delle richieste, per gestire e proteggere l’hosting. GitHub Issues e i link esterni sono regolati dalle politiche dei rispettivi fornitori: l’informativa sulla privacy di GitHub e l’informativa sulla privacy di Apple.
