Aide et assistance

Passez en revue les suspects habituels ci-dessous. Si ce n’est aucun d’eux, écrivez-moi et j’essaierai de comprendre ce qui s’est passé.

Les guides d’utilisation de DayHand — premiers pas, piles et dates, revues, synchronisation, importations et sauvegardes, gratuit et payant — n’existent qu’en anglais : ouvrir les guides.

Je ne retrouve pas mes tâches

Commencez par effacer la recherche, les filtres de catégorie et de projet, et le drapeau. Regardez ensuite dans les autres piles et dans Chronologie ; une tâche que vous avez cochée s’y trouve. Si un second appareil affiche autre chose, lisez la liste de contrôle de la synchronisation (en anglais) avant de remplacer ou de restaurer quoi que ce soit.

Si vous êtes passé d’une version Mac compilée par vous-même à celle de TestFlight, l’app range ses données ailleurs et démarre donc vide. Rien n’est perdu. Si vous utilisiez un fichier de synchronisation iCloud, choisissez Utiliser un fichier existant et pointez-le vers le même fichier, avec Fusionner.

Un rappel est resté silencieux

  • Les notifications sont-elles autorisées pour DayHand dans les réglages système ? Un mode de concentration les retient-il ?
  • Les rappels se déclenchent à 9 h le jour prévu. Pour un rappel d’aujourd’hui défini après 9 h, aucune notification ne viendra.
  • Une tâche terminée, ou un rappel que vous avez supprimé, ne notifie pas. Un rappel auquel vous avez déjà répondu ce jour-là n’a aucune raison de le faire non plus.
  • Ouvrez DayHand. L’app actualise son planning au démarrage, ce qui compte surtout après une modification faite sur un autre appareil.

Si le drapeau et le badge de l’icône affichent des nombres différents, c’est voulu. Voici pourquoi (en anglais).

Mes tâches importées sont différentes

Chaque importation a ses limites pour les dates, les tâches récurrentes et les détails supplémentaires. Le guide d’importation (en anglais) les énumère. Regardez d’abord dans les Notes de la tâche : ce que DayHand n’a pas pu placer y est généralement conservé sous forme de texte.

Écrivez-moi

DayHand est fait par une seule personne ; il n’y a donc pas de guichet de tickets. Pendant la bêta, utilisez Envoyer des commentaires sur la bêta dans TestFlight. Vous pouvez aussi ouvrir un ticket sur GitHub, pour un bug, une question ou une idée. Cela demande un compte GitHub ; lire ces pages, non.

Il m’est très utile que vous m’indiquiez :

  • votre appareil, sa version du système, ainsi que la version et le numéro de build de DayHand ;
  • ce que vous avez fait, ce que vous attendiez et ce qui s’est passé ;
  • le message exact affiché à l’écran, s’il y en avait un ;
  • pour un problème de synchronisation, quels appareils sont concernés et ce qu’indique l’état de synchronisation sur chacun.
Les tickets GitHub sont publics. Masquez les titres de tâches privées sur les captures d’écran. Ne joignez ni votre fichier de tâches ni une sauvegarde, ni mots de passe ou données personnelles. Un petit exemple inventé qui montre le même problème est de toute façon préférable.

Avant d’écrire, vous pouvez consulter les signalements existants ; quelqu’un a peut-être déjà rencontré le même problème.
