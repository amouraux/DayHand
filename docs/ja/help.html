ヘルプ · サポート

ヘルプとサポート

小さなアプリのための短いマニュアルです。初めての方は上から順にお読みください。うまく動かないときはトラブルシューティングへ。それでも解決しなければ、私にご連絡ください。

最初のタスク

まずは実際のタスクを数件から始めましょう。プロジェクトやカテゴリは、必要になってからで十分です。

1. 書き留める

+をタップしてタスクを入力し、保存します。タスクは「インボックス」に入り、扱いを決めるまでそこで待ちます。タスクに必要なものはそれだけで、プロジェクトも日付もいりません。

2. 居場所を決める

タスクをタップ(Macではクリック)すると、できる操作が表示されます。中心になるのは移動です。取り組んでいることは「今」に置きましょう。何日でも何週間でもそこに置けますし、勝手に押し出されることもありません。「次」は次に取りかかるもの、「あとで」は取っておきたいけれど今は手を付けないもの、「待機中」は誰かの返事や対応を待っているものです。

スタックについては次のセクションで詳しく説明します。

3. 関連するものをまとめる

タスクの操作から編集を選ぶと、詳細を変更したりメモを追加したりできます。

プロジェクトは、旅行、講座、顧客など、ひとまとまりの仕事のタスクを集めます。カテゴリは、仕事や家庭のような生活の大きな区分です。グループはプロジェクトをまとめます。プロジェクトは1つのカテゴリに属し、1つのグループに入れることができます。どちらを変えても、そのプロジェクトのすべてのタスクに反映されます。プロジェクトのないタスクにもカテゴリを付けられます。

4. 見つける

検索とフィルタを使うと、1つのプロジェクトやカテゴリに集中できます。Macと横向きのiPadでは、サイドバーにカテゴリ、グループ、プロジェクトが並びます。フィルタから名前の変更や並べ替えもできます。

その他 → 外観で、自動、ライト、ダークから選べます。自動はデバイスの設定に従います。

5. 完了する

作業が終わったら丸をタップします。完了したタスクはスタックから外れますが、消えるわけではありません。その他 → タイムラインには完了したものが日ごとに並び、早まって完了にしたタスクは開き直せます。

リストが古びてきたと感じたら、レビューを試してみてください。

試してみましょう。「庭の計画を立てる」を追加します。アイデアを集めている間は「今」に置きます。業者に見積もりを依頼したら「待機中」に移し、催促したい日にリマインダーを設定します。1つのタスクを最初から最後まで追えます。

タスクの居場所と、見るタイミング

スタックは、そのタスクをどうするつもりかを表します。日付は、いつ知らせてほしいかを表します。DayHandはこの2つを意図的に分けています。

5つのスタック

インボックス
書き留めたばかりで、まだ置き場所を決めていないもの。
今
数日かかるものも含め、今まさに取り組んでいるもの。
次
余裕ができたら取りかかるもの。明日という意味ではありません。
あとで
取っておきたいけれど、まだ手を付けないアイデアや計画。
待機中
先に進む前に、返事、納品、決定、または他の誰かの作業が必要なもの。「あとで」とは違い、できるなら進めたいものです。

日付がタスクを動かすことはありません。時間が過ぎてもタスクの場所は変わらず、いつ動かすかはあなたが決めます。

1週間のタスクを例にします。月曜日に「プレゼンの準備」を追加し、火曜日のリマインダーと金曜日の期限を付けます。火曜日、リマインダーが着手を促すので「今」に移します。もっと急ぎのことが入ったため「あとで」に移し、水曜日に新しいリマインダーを設定します。水曜日には「今」に戻します。木曜日、下書きを同僚に送って「待機中」に置きます。金曜日にフィードバックが届き、仕上げて完了にします。タスクは1つ、期限は一度も変わらず、「遅れ」になったことはありません。

リマインダー:もう一度見るために

タスクの操作からリマインド…を選ぶか、エディタで設定します。リマインダーを変更…で別の日を選べ、リマインダーを削除で解除できます。

リマインダーは、DayHandの通知が許可されていれば、選んだ日の午前9時に通知されます。今日の午前9時を過ぎてから設定した場合は、通知する時刻がもうないため、タスクは「今が期日」として印が付くだけで、通知は届きません。その場合は日付ピッカーに表示されます。(以前のバージョンで作ったリマインダーは、元の時刻のままのことがあります。)

通知をタップすると、DayHandがそのタスクを開きます。通知を消しただけでは応答にはならず、リマインダーはアプリ内で待ち続けます。応答するには、ここに残す(正しいスタックにある、ありがとう)を選ぶか、タスクを移動する、完了する、別の日を選ぶのいずれかです。

色、旗、バッジ

  • オレンジの縁:リマインダーが3日以内に来ます。
  • 赤の縁:リマインダーが今日、またはすでに過ぎています。「これを見ようと思っていた」という意味で、「遅れている」という意味ではありません。
  • アプリ内の旗:どのスタックでも、赤またはオレンジの縁が付いたタスクをすべて集めます。数字は赤の数です。
  • アプリアイコンのバッジ:届いていて、まだ応答していないリマインダーの数です。

そのため、旗とバッジの数が一致しないことがありますが、問題ありません。リマインダーに「ここに残す」と応答するとバッジは減りますが、タスクは赤い縁のまま、日付を変更または解除するまで旗に残ります。

期限:その日までに終えるもの

提出、更新、納品のように本当のゴールがあるときは、エディタで期限を追加します。新しく追加するには、まずリマインダーを設定すると、期限の欄が現れます。あとでリマインダーを解除しても、すでに設定してあった期限は表示され、編集もできます。

期限は通知を送らず、何も動かしません。タスクに書かれているだけです。何か手を打てるよう、余裕をもってリマインダーを設定してください。

通知が来ない?確認することを見てください。

レビュー

その他 → レビューを開いて、アシスタントを選びます。どのアシスタントも、1つのタスクまたは1つのプロジェクトについて1つだけ質問するので、長いリストをスクロールするのではなく、その場で決められます。

タスクをレビューする

インボックスをレビュー
これはどこに置く?新しいタスクを合うスタックに移します。まだ決められなければそのままにします。
「今」をレビュー
まだ積極的に取り組んでいる?取り組み中のものは残し、変わったものは移動し、終わったものは完了にします。
「待機中」をレビュー
これは先に進められる?本当に止まっているものは残し、そうでないものは戻し、催促のためにリマインダーを設定します。
「次」と「あとで」をレビュー
まだ関係がある?大事なものは前に出し、そうでないものは手放します。
すべてのタスクをレビュー
「インボックス」、「今」、「待機中」、続いて「次」と「あとで」を一度に回ります。一巡の途中で移動したタスクは、その巡回では戻ってきません。

アシスタントはタスクと、そのスタックに入ってからの期間を表示します。そのままにする、移動する、編集する、完了する、削除する、のいずれかを選びます。スタックのボタンはタスクが変わっても同じ位置にあるので、親指が覚えてくれます。

途中でやめて、あとで戻れます。進み具合はそのデバイスにだけ保存され、別のデバイスは自分の巡回を始めます。その間に届いたタスクは次の巡回で扱われます。

レビューは決定であり、締め切りではありません。1か月そこにあるタスクでも、「「今」に残す」は立派な答えです。

プロジェクトをレビューする

プロジェクトをレビューは、プロジェクトごとに1つ質問します。この先の道筋ははっきりしている?タスクがスタック別に表示され、カテゴリとグループも見えます。

  • 問題なし — 次のプロジェクトへ:問題なし、次へ進みます。
  • タスクを追加:足りない手順を書き留めます。このプロジェクトはすでに選択されています。
  • これらのタスクをレビュー:このプロジェクトのタスクを1つずつ確認します。
  • プロジェクトを編集:名前、カテゴリ、グループを変更します。

追加、編集、レビューのあとは、同じプロジェクトに戻ります。左上のシェブロンは直前のプロジェクトに戻り、×はレビューを終了します。

未完了の仕事があるプロジェクトが先に来ます。やることがなくなったプロジェクトはその次に来るので、アーカイブできます。アーカイブ済みのプロジェクトは飛ばされ、プロジェクトのないタスクはタスクのレビューに出てきます。

未完了のタスクがあるプロジェクトをアーカイブしようとすると、先に完了するよう求められます。アーカイブは終わった仕事のためのもので、プロジェクトを眠らせる手段ではありません。そのためには「あとで」を使ってください。

振り返る

その他 → タイムラインと、各プロジェクトの履歴には、完了したものが表示されます。これらは、まだ終わっていない仕事を扱うアシスタントとは別のものです。

同期

DayHandは、あなたのiCloud Drive内の1つのファイルを通してタスクを共有します。DayHandのアカウントもサーバーもありません。デバイスが1台だけなら、これは不要です。

1台目のデバイス

  1. iCloud Driveがオンになっていることを確認します。
  2. その他 → 同期 → 同期ファイルを作成…を開きます。
  3. あとで見つけられるiCloud Driveのフォルダにファイルを保存します。
  4. 次のデバイスを設定する前に、iCloudがアップロードを終えるまで少し待ちます。

それ以外のデバイス

  1. 同じApple IDでサインインし、ファイルのダウンロードが済んでいることを確認します。
  2. その他 → 同期 → 既存の同期ファイルを使う…を開きます。
  3. このデバイスと統合を選びます。両方のタスクが残ります。
  4. 1台目で作成した同じファイルを選びます。同じ名前で2つ目のファイルを作らないでください。名前が同じでも、別々のファイルは別のファイルです。
  5. 両方のデバイスで、タスクと同期の状態を確認します。
置き換えは別の操作です。「このデバイスのタスクを置き換え」は、このデバイスにあるものを捨てて、ファイルのタスクに入れ替えます。今のリストが必要になるかもしれないときは、先にバックアップを取ってください。

DayHandは、選んだファイルが本当にDayHandのファイルかどうかを確認します。スプレッドシート、他人のJSON、写真などは、同期がファイルに書き込んで上書きしてしまうため、拒否されます。

日々の使い方

各デバイスが自分のコピーを持つので、オフラインでも作業できます。変更は、iCloudがファイルを届け、DayHandがそれを読み込んだ時点でファイルを介して合流します。時間がかかることもあり、閉じているアプリは急ぎません。即時反映は期待しないでください。

両方のデバイスがオフラインのときに、同じタスクを2台で編集するのは避けてください。1つのタスクの2つのバージョンが競合した場合は、新しい変更が優先されます。DayHandは、同じタイトルへの2つの変更を統合しません。

デバイス間で食い違うとき

  1. 各デバイスでその他 → 同期を見ます。「同期していません」は、そのデバイスにファイルがつながっていないという意味です。
  2. 両方が同じ場所の同じファイルを使っているか確認します。名前が同じだけでは足りません。
  3. iCloud Driveに接続していて、ファイルのダウンロードが終わっているかを、ファイルアプリまたはFinderで確認します。
  4. 両方のデバイスでDayHandを開き、今すぐ同期をタップします。ボタンの下の行を読みます。
  5. ファイルを移動または名前変更してしまい、片方のデバイスが見失った場合は、そのデバイスのバックアップを取り、古いリンクの使用をやめてから、正しいファイルをもう一度選び、マージを選びます。

接続を解除する

このファイルの使用をやめるで、このデバイスの接続を解除します。タスクは残ります。何もつながずに、一度保存したコピーを見たいだけなら、代わりにファイルから復元…を使います。

まだ解決しませんか?私に知らせてください。各デバイスの同期の状態に何が表示されているかも添えてください。

読み込み、書き出し、バックアップ

タスクはあなたのものです。取り込み、持ち出し、取り戻せます。読み込みは一度きりのコピーで、DayHandは元のアプリとつながったままにはなりません。

Appleのリマインダーから

  1. その他 → タスク → Appleのリマインダーから読み込む…を開きます。
  2. リマインダーへのアクセスを許可します。リストを読むには、Appleが用意する「フルアクセス」しかありません。DayHandは読み取るだけで、変更はしません。
  3. リスト、タスクを入れるスタック、プロジェクトまたはカテゴリを選び、期日も持ち込むかどうかを選びます。
  4. プレビューを確認してから、確定します。

期日はDayHandの午前9時のリマインダーになり、期限にはなりません。元の日付と時刻はメモに残ります。繰り返しのリマインダーはスキップされます。サブタスク、タグ、添付ファイル、スマートリストのルールは持ち込まれません。メモ、リンク、場所、優先度は、ある場合にテキストとして入ります。

先にバックアップが取られます。同じデバイスで同じリストをもう一度読み込むと、すでに取り込んだタスク(削除したものを含む)はスキップされます。別のデバイスや、アカウントをリセットしたあとでは、重複することがあります。

Todoistから

  1. Todoistで、プロジェクトをCSVファイルとして書き出します。
  2. その他 → タスク → Todoistから読み込む…を開き、そのファイルを1つ以上選びます。
  3. ファイルごとに、スタック、プロジェクト、カテゴリを選び、日付のオプションを確認します。
  4. プレビューと警告があればそれを読んでから、読み込みます。

Todoistのプロジェクトの書き出しには、完了済みのタスクは含まれません。認識できる日付は午前9時のリマインダーになり、期限は期限のままです。説明、コメント、そのほか読み取れる詳細はメモに入ります。サブタスクは独立したタスクになり、親とセクションが記録されます。添付ファイルはダウンロードされません。繰り返しの予定は再作成されません。DayHandが理解できない日付には印が付き、それでもタスクを読み込むと、元の日付の文字列がメモに残ります。

先にバックアップが取られます。変更せず同じ名前のファイルをもう一度読み込むと、すでに取り込んだ行はスキップされます。書き出したファイルを編集したり名前を変えたりすると、重複することがあります。

通知に注意してください。AppleのリマインダーとTodoistは自分の通知を送り続け、未来のリマインダーを読み込むと、DayHandからも知らせが来ます。どのアプリに通知させるかを決めてください。

DayHandのCSV

その他 → タスク → CSVとして書き出す…で、持ち運べるコピーを保存します。CSVから読み込む…には、DayHandのCSVを今の内容に統合する既存のタスクに追加と、先に今のタスクを消すすべてのタスクを置き換えがあります。後者を選ぶ前によく考えてください。

Todoistのファイルには、Todoistの読み込みを使ってください。ほかのアプリのCSVファイルは、DayHandの形式と一致しません。自分でファイルを用意したいときは、まず数件のタスクを書き出して、その構造をまねてください。

バックアップ

その他 → バックアップで、大きな操作の前に今すぐバックアップをタップします。DayHandも、アプリを開いた日に、昨日、一昨日、約1週間前という少数のローテーション枠で自動的にバックアップを取ります。これは安全網であって、アーカイブではありません。同じ日に手動でもう一度バックアップを取ると、最初のものが置き換わります。

好きな場所にコピーを保管するには、バックアップの共有操作を使います。Macでは、バックアップを右クリックして、復元、共有、削除ができます。iPhoneやiPadでは、長押しします。スワイプでも操作できます。

復元する

  1. 今のタスクが必要になるかもしれないときは、先にバックアップを取るか、書き出してください。
  2. リストのバックアップをタップするか、ファイルから復元…を選んで任意のDayHandファイルを選択します。
  3. 確認画面にある2つの件数を読みます。ここにあるタスクの数と、ファイルにあるタスクの数です。復元すると今のタスクが置き換えられ、カテゴリとプロジェクトも戻ります。
  4. 欲しいコピーであることを確かめてから確定します。

ファイルから復元…はファイルを読み取るだけです。同期のためにつなぐことはしません。同期している場合は、その状態のままなので、復元した内容は他のデバイスにも届きます。コピーだけを単独で見たいときは、先に同期をやめてください。

共有ファイルへの継続的な接続については、同期を見てください。

無料と有料

計画は、無料のアプリに、残りを解放する買い切りを1つ用意することです。サブスクリプションはありません。

現在の状況。これはベータ版で、すべて解放されています。購入、30日間のお試し、購入の復元はまだ作っていません。以下は計画で、何を期待できるかをお伝えするものです。ベータ版にあるテスト用スイッチで、自分のデバイスで上限を試しています。

無料

タスク、カテゴリ、グループは無制限で、アクティブなプロジェクトは3つまで、完了したタスクは直近30日分です。レビュー、メモ、リマインダー、期限、同期、読み込み、書き出し、バックアップはすべて含まれます。便利な部分を壁の向こうに置きたくありません。

解放

一度だけの購入で、アクティブなプロジェクトが無制限になり、完了したタスクの全履歴が見られます。同じApple IDで、iPhone、iPad、Macで使えます。価格はできしだいここに載せます。

上限に達したとき

アーカイブしたプロジェクトは数に入らないので、終わったプロジェクトをアーカイブすれば1つ空き、アーカイブから戻せば1つ埋まります。タスクを書き留めることは決して止められません。すでにあるプロジェクトは、読み込みで3つを超えても、読み取りも編集もできます。

30日より前に完了したタスクは、タイムラインで非表示になるだけです。検索では引き続き見つかり、バックアップとCSVの書き出しにも残ります。支払いがないという理由で何かが削除されることはありません。

お試し

あなたが開始する30日間のお試しを考えています。終わるとアプリは無料版に戻ります。請求はなく、自動で何かが起きることもありません。まだ利用できず、購入の復元も同様です。出た時点で、ここで両方を説明します。

トラブルシューティング

まず、よくある原因を下から確認してみてください。どれにも当てはまらない場合は、私に連絡してください。何が起きたのか調べてみます。

タスクが見つかりません

まず、検索、カテゴリとプロジェクトのフィルタ、フラグを解除してください。次に、ほかのスタックとタイムラインを確認します。完了にしたタスクはそこにあります。2台目のデバイスで表示が違う場合は、何かを置き換えたり復元したりする前に、同期のチェックリストを読んでください。

リマインダーが鳴りませんでした

  • システム設定で、DayHandの通知は許可されていますか？集中モードが通知を止めていませんか？
  • リマインダーは、その日の午前9時に鳴ります。午前9時を過ぎてから今日のリマインダーを設定した場合、通知は届きません。
  • 完了したタスクや、削除したリマインダーは通知されません。その日にすでに対応したリマインダーも、通知する理由がありません。
  • DayHandを開いてください。Appは起動時にスケジュールを更新します。ほかのデバイスで何かを変更したあとは、特に重要です。

フラグとアイコンのバッジで数が違うのは、意図したものです。理由はこちら。

読み込んだタスクの見え方が違います

読み込みごとに、日付、繰り返しのタスク、追加の詳細について制限があります。読み込みガイドに一覧があります。まずタスクのメモを見てください。DayHandが配置できなかった内容は、たいていそこにテキストとして残っています。

お問い合わせ

DayHandは1人で作っているため、チケット窓口はありません。連絡いただくには、不具合、質問、アイデアについてGitHubでIssueを作成していただくのが最適です。これにはGitHubアカウントが必要ですが、このページを読むのには必要ありません。

次のことを教えてもらえると、とても助かります。

  • お使いのデバイス、システムのバージョン、DayHandのバージョンとビルド
  • 行った操作、期待していたこと、実際に起きたこと
  • 画面に表示されたメッセージがあれば、その正確な文面
  • 同期の問題の場合は、どのデバイスか、それぞれの同期の状態
GitHubのIssueは公開されます。 スクリーンショットでは、個人的なタスクのタイトルを隠してください。タスクのファイルやバックアップ、パスワード、個人情報は添付しないでください。同じ問題を再現できる小さな架空の例のほうが、いずれにしても役に立ちます。

書き込む前に、既存の報告を見てください。すでにほかの人が同じ問題に遭遇しているかもしれません。
