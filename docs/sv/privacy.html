Integritetspolicy

Dina uppgifter hör hemma i dina egna filer. DayHand skickar inte innehållet i dina uppgifter till utvecklaren och driver ingen server som lagrar dem.

Översikt

Den här policyn gäller DayHand för iPhone, iPad och Mac och förklarar separat hur information som du väljer att dela via support eller den här webbplatsen hanteras.

Appen har inget DayHand-konto, ingen reklam, ingen spårning och inget analys-SDK från tredje part. Utvecklaren får inte dina uppgiftslistor, anteckningar eller importerade påminnelser vid normal användning av appen. DayHand säljer inte dina personuppgifter och använder dem inte för reklam.

Uppgifter, inställningar och säkerhetskopior

Uppgifter, anteckningar, projekt, kategorier, grupper, datum och information om vad som är klart lagras i ett DayHand-dokument på din enhet. Appen sparar också inställningar och granskningsförlopp lokalt. Informationen används för att tillhandahålla uppgiftshantering, sökning, granskningar och återställning.

DayHand skapar lokala säkerhetskopior och låter dig göra och dela fler kopior. Säkerhetskopior och exporter kan innehålla samma privata information som din uppgiftslista. Deras filnamn kan innehålla ett enhetsnamn. De finns kvar på de platser där du eller appen sparade dem; de laddas inte upp till utvecklaren.

DayHand-dokument och CSV-exporter är läsbara filer; appen lägger inte till något eget lösenordsskydd eller någon egen kryptering. Åtkomsten beror på enhetens säkerhet, filrättigheterna och den lagringstjänst du väljer.

Synkronisering via din iCloud Drive

Om du aktiverar synkronisering läser och skriver DayHand den fil du väljer i din iCloud Drive. Apple överför filen mellan dina enheter via ditt iCloud-konto. Filen går inte via någon DayHand-server, och synkroniseringen ger inte utvecklaren åtkomst till den.

Apples hantering av iCloud-data styrs av Apples integritetspolicy och dina kontoinställningar. Om du lägger en fil i en delad mapp eller delar en kopia med någon kan den personen kanske läsa innehållet.

Importera uppgifter

Importen från Apple Påminnelser ber om åtkomst för att läsa dina listor. DayHand använder behörigheten för att kopiera de påminnelser du väljer och ändrar inte originalen. Importerat innehåll, inklusive anteckningar som stöds och andra detaljer, blir en del av dina DayHand-filer.

Import av Todoist- och DayHand-CSV läser filer som du väljer på din enhet. DayHand frågar inte efter ditt Todoist-lösenord och ansluter inte till ditt Todoist-konto. De här importerna är engångskopior, inte pågående anslutningar till den ursprungliga tjänsten.

Påminnelser och aviseringar

DayHand schemalägger lokala aviseringar via Apples operativsystem. Innehållet i en avisering kan inkludera en uppgifts titel, som kan visas på din låsskärm beroende på dina aviseringsinställningar. DayHand skickar inte uppgiftstitlar till någon aviseringsserver som drivs av utvecklaren.

Apple-tjänster och köp

Apple hanterar nedladdningar från App Store, distribution via TestFlight och all diagnostikinformation som du väljer att dela via Apples inställningar. Apple kan göra diagnostikrapporter eller betafeedback tillgängliga för utvecklaren. DayHand innehåller ingen ytterligare analys- eller kraschrapporteringstjänst.

Den nuvarande betan har ännu inte de planerade flödena för köp, provperiod och återställning av köp. När de blir tillgängliga hanteras köp av Apple, och DayHand använder StoreKit-köpinformation för att avgöra åtkomsten på enheten. Utvecklaren får inte dina betalkortsuppgifter via appen. Den här policyn uppdateras om sättet att hantera köpdata ändras.

Dina integritetsval och radering av data

  • Använd DayHand lokalt: synkronisering krävs inte. Om du vill koppla bort en länkad fil väljer du Mer → Synkronisering → Sluta använda den här filen. Dina lokala uppgifter behålls och den delade filen tas inte bort.
  • Återkalla åtkomsten till Påminnelser: ändra DayHands behörighet för Påminnelser i enhetens systeminställningar. Att återkalla behörigheten tar inte bort uppgifter som redan importerats; ta bort dem separat om du inte vill ha dem kvar.
  • Styr aviseringar: stäng av aviseringar eller dölj förhandsvisningarna i systeminställningarna. Du kan också rensa påminnelser för enskilda uppgifter i DayHand.
  • Exportera ditt arbete: använd Mer → Uppgifter → Exportera som CSV, eller dela en säkerhetskopia från Mer → Säkerhetskopior.
  • Ta bort uppgifter: ta bort dem i appen. När synkronisering är aktiverad kan borttagningar spridas till anslutna enheter. Äldre säkerhetskopior och exporterade kopior kan fortfarande innehålla det borttagna innehållet.
  • Ta bort sparade kopior: ta bort säkerhetskopior från Mer → Säkerhetskopior och ta bort exporter eller delade filer du inte längre behöver i Filer eller Finder. Kontrollera också andra enheter och din lagringstjänsts funktioner för nyligen borttagna objekt eller återställning.

Aktiva uppgiftsdata behålls tills du ändrar eller tar bort dem. Automatiska säkerhetskopior roterar; manuella säkerhetskopior och kopior du delar finns kvar tills de ersätts eller tas bort. Raderingsposter som används för synkronisering kan innehålla uppgifts-id och raderingsdatum, men inte uppgifternas innehåll. Att ta bort appen tar inte bort separat sparade iCloud-filer, exporter eller kopior på andra enheter.

Det finns inget DayHand-konto att stänga. Utvecklaren kan inte hämta eller på distans radera uppgiftsfiler som bara finns på dina enheter eller i ditt lagringskonto.

Information du skickar och hur du kontaktar oss

För frågor om den här policyn eller en integritetsbegäran kontaktar du DayHands utvecklare via supportsidan. Under betan kan du skicka feedback via TestFlight. GitHub Issues finns också för allmänna frågor och felrapporter.

Om du skickar feedback, en diagnostikrapport eller ett supportmeddelande får utvecklaren den information du tar med och den som kanalen tillhandahåller, till exempel en kontaktadress, enhetsuppgifter eller bilagor. Informationen används för att svara, felsöka och förbättra DayHand. Supportuppgifter kan sparas så länge det behövs för att lösa ärendet och följa upp problemet; kontakta utvecklaren via samma kanal om du vill att information du lämnat raderas. Apple och GitHub hanterar sina egna kopior och sin egen lagring enligt sina policyer.

GitHub-ärenden är offentliga. Publicera inga privata uppgifter, säkerhetskopior, inloggningsuppgifter eller personuppgifter där. Använd ett påhittat exempel när det går. För en integritetsbegäran börjar du utan känsliga detaljer och frågar efter ett lämpligt sätt att gå vidare.

Den här webbplatsen och externa tjänster

Den här webbplatsen finns på GitHub Pages. Den lägger inte till analysskript eller reklamcookies. GitHub kan behandla anslutningsinformation, som IP-adresser och begärandeloggar, för att driva och skydda värdtjänsten. GitHub Issues och externa länkar omfattas av respektive leverantörs policyer: GitHubs sekretesspolicy och Apples integritetspolicy.

Ändringar i den här policyn

Uppdateringar publiceras på den här sidan med ett nytt datum. Väsentliga ändringar i hur appen hanterar data speglas här och, där det krävs, i appens meddelanden och i App Stores integritetsuppgifter.
