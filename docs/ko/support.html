할 일을 찾을 수 없습니다

먼저 검색, 카테고리와 프로젝트 필터, 깃발을 해제하세요. 그런 다음 다른 스택과 타임라인을(를) 확인하세요. 완료로 표시한 할 일은 거기에 있습니다. 두 번째 기기에 다른 내용이 보이면, 무언가를 교체하거나 복원하기 전에 동기화 체크리스트 (영어)를 읽어 보세요.

직접 빌드한 Mac 버전에서 TestFlight 버전으로 옮겼다면, 앱이 데이터를 다른 위치에 저장하므로 비어 있는 상태로 시작합니다. 잃어버린 것은 없습니다. iCloud 동기화 파일을 사용했다면 기존 동기화 파일 사용을(를) 선택하고 같은 파일을 지정한 뒤 병합하세요.

미리 알림이 울리지 않았습니다

  • 시스템 설정에서 DayHand의 알림이 허용되어 있나요? 집중 모드가 알림을 막고 있지는 않나요?
  • 미리 알림은 해당 날짜 오전 9시에 울립니다. 오전 9시 이후에 설정한 오늘의 미리 알림에는 알림이 오지 않습니다.
  • 완료한 할 일이나 지운 미리 알림은 알리지 않습니다. 그날 이미 응답한 미리 알림도 알릴 이유가 없습니다.
  • DayHand를 여세요. 앱은 시작할 때 일정을 새로 고치며, 다른 기기에서 무언가를 바꾼 뒤에 특히 중요합니다.

깃발과 아이콘 배지의 숫자가 다른 것은 의도된 동작입니다. 이유는 여기에서 확인하세요 (영어).

가져온 할 일이 다르게 보입니다

가져오기마다 날짜, 반복 할 일, 추가 세부 정보에 제한이 있습니다. 가져오기 안내 (영어)에 목록이 있습니다. 먼저 할 일의 메모을(를) 확인하세요. DayHand가 배치하지 못한 내용은 대개 거기에 텍스트로 남아 있습니다.

알려 주세요

DayHand는 한 사람이 만들기 때문에 티켓 창구가 없습니다. 베타 기간에는 TestFlight의 베타 피드백 보내기를 사용하세요. 버그, 질문, 아이디어는 GitHub에서 이슈를 열어 알려 주셔도 됩니다. GitHub 계정이 필요하지만, 이 페이지를 읽는 데는 필요 없습니다.

다음을 알려 주시면 큰 도움이 됩니다.

  • 기기, 시스템 버전, DayHand 버전과 빌드
  • 한 일, 기대한 결과, 실제로 일어난 일
  • 화면에 표시된 메시지가 있다면 정확한 문구
  • 동기화 문제라면 어떤 기기인지, 각 기기의 동기화 상태가 무엇인지
GitHub 이슈는 공개됩니다. 스크린샷에서는 개인적인 할 일 제목을 가리세요. 할 일 파일이나 백업, 암호, 개인정보를 첨부하지 마세요. 같은 문제를 보여 주는 작은 예시를 지어내는 것이 어차피 더 좋습니다.

글을 쓰기 전에 기존 보고를 둘러보세요. 이미 누군가 같은 문제를 겪었을 수 있습니다.

이 페이지는 영어 지원 페이지의 번역입니다. 링크된 안내는 영어입니다.
