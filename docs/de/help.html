Hilfe und Support

Sehen Sie sich unten die üblichen Verdächtigen an. Wenn es keiner davon ist, schreiben Sie mir, dann versuche ich herauszufinden, was passiert ist.

Die Anleitungen zur Nutzung von DayHand – erste Schritte, Stapel und Termine, Durchsichten, Sync, Importe und Backups, Gratis und Bezahlt – gibt es nur auf Englisch: Anleitungen öffnen.

Ich finde meine Aufgaben nicht

Löschen Sie zuerst die Suche, die Kategorie- und Projektfilter und die Flagge. Schauen Sie dann in die anderen Stapel und in die Zeitleiste; eine abgehakte Aufgabe finden Sie dort. Wenn ein zweites Gerät etwas anderes anzeigt, lesen Sie die Sync-Checkliste (Englisch), bevor Sie etwas ersetzen oder wiederherstellen.

Wenn Sie von einer selbst gebauten Mac-Version zur TestFlight-Version gewechselt sind, speichert die App ihre Daten an einem anderen Ort und startet deshalb leer. Es ist nichts verloren. Wenn Sie eine iCloud-Sync-Datei genutzt haben, wählen Sie Vorhandene Datei verwenden und zeigen Sie auf dieselbe Datei, mit Zusammenführen.

Eine Erinnerung blieb stumm

  • Sind Mitteilungen für DayHand in den Systemeinstellungen erlaubt? Hält ein Fokus sie zurück?
  • Erinnerungen werden an ihrem Tag um 9 Uhr ausgelöst. Für eine Erinnerung für heute, die nach 9 Uhr gesetzt wurde, kommt keine Mitteilung mehr.
  • Eine erledigte Aufgabe oder eine gelöschte Erinnerung meldet sich nicht. Eine für diesen Tag bereits beantwortete Erinnerung hat dazu auch keinen Grund.
  • Öffnen Sie DayHand. Beim Start aktualisiert die App ihren Zeitplan, was vor allem nach Änderungen auf einem anderen Gerät wichtig ist.

Wenn die Flagge und das Badge auf dem Symbol unterschiedliche Zahlen zeigen, ist das Absicht. Hier steht, warum (Englisch).

Meine importierten Aufgaben sehen anders aus

Jeder Import hat Grenzen bei Terminen, wiederkehrenden Aufgaben und zusätzlichen Details. Die Import-Anleitung (Englisch) listet sie auf. Schauen Sie zuerst in die Notizen der Aufgabe: Was DayHand nicht zuordnen konnte, steht meist dort als Text.

Schreiben Sie mir

DayHand wird von einer einzelnen Person gemacht, es gibt also kein Ticketsystem. Nutzen Sie während der Beta Beta-Feedback senden in TestFlight. Sie können auch ein Issue auf GitHub eröffnen, für einen Fehler, eine Frage oder eine Idee. Dafür brauchen Sie ein GitHub-Konto; zum Lesen dieser Seiten nicht.

Es hilft sehr, wenn Sie mir Folgendes mitteilen:

  • Ihr Gerät, dessen Systemversion sowie die Version und den Build von DayHand;
  • was Sie getan haben, was Sie erwartet haben und was geschehen ist;
  • die genaue Meldung auf dem Bildschirm, falls es eine gab;
  • bei Sync-Problemen: welche Geräte betroffen sind und was der Sync-Status auf jedem anzeigt.
GitHub-Issues sind öffentlich. Schwärzen Sie private Aufgabentitel in Screenshots. Hängen Sie weder Ihre Aufgabendatei noch ein Backup an, und keine Passwörter oder persönlichen Angaben. Ein kleines erfundenes Beispiel, das dasselbe Problem zeigt, ist ohnehin besser.

Bevor Sie schreiben, können Sie die vorhandenen Meldungen durchsehen; vielleicht ist jemand schon darauf gestoßen.

Diese Seite ist eine Übersetzung der englischen Support-Seite. Die verlinkten Anleitungen sind auf Englisch.

Für die Beta geschrieben, Oktober 2026. Wenn eine Taste auf Ihrem Bildschirm anders heißt, hat sich die App weiterentwickelt und diese Seite nicht — sagen Sie es mir.
