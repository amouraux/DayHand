Hilfe und Support

Ein kurzes Handbuch für eine kleine App. Neu hier? Fangen Sie oben an. Etwas funktioniert nicht? Gehen Sie zur Fehlerbehebung, und wenn das nicht hilft, schreiben Sie mir.

Ihre ersten Aufgaben

Beginnen Sie mit ein paar echten Aufgaben. Projekte und Kategorien können warten, bis Sie sie brauchen.

1. Etwas festhalten

Tippen Sie auf +, geben Sie die Aufgabe ein und sichern Sie sie. Sie landet in „Eingang“, wo Dinge warten, bis Sie entschieden haben, was damit geschieht. Mehr braucht eine Aufgabe nicht: kein Projekt, kein Datum.

2. Einen Platz zuweisen

Tippen Sie auf eine Aufgabe (auf einem Mac: klicken), um zu sehen, was Sie damit tun können. Das Verschieben ist die Hauptsache. Legen Sie, woran Sie gerade arbeiten, in „Jetzt“. Dort kann es Tage oder Wochen bleiben; nichts drängt es hinaus. „Als Nächstes“ ist, was Sie danach angehen, „Später“ ist für das, was Sie behalten, aber nicht anfassen wollen, und „Wartet“ ist für das, was an jemand anderem hängt.

Der nächste Abschnitt erklärt die Stapel genauer.

3. Zusammengehöriges beisammen halten

Wählen Sie in den Aktionen einer Aufgabe Bearbeiten, um ihre Details zu ändern und Notizen hinzuzufügen.

Ein Projekt sammelt die Aufgaben eines Vorhabens: einer Reise, eines Kurses, eines Kunden. Eine Kategorie ist ein großer Bereich Ihres Lebens, etwa Arbeit oder Zuhause. Eine Gruppe fasst Projekte zusammen. Ein Projekt gehört zu einer Kategorie und kann in einer Gruppe stehen, und eine Änderung von beidem gilt für jede Aufgabe des Projekts. Eine Aufgabe ohne Projekt kann trotzdem eine Kategorie haben.

4. Sich zurechtfinden

Suche und Filter helfen Ihnen, sich auf ein Projekt oder eine Kategorie zu konzentrieren. Auf einem Mac und auf einem iPad im Querformat listet eine Seitenleiste Ihre Kategorien, Gruppen und Projekte auf. Im Filter können Sie sie umbenennen und neu ordnen.

Unter Mehr → Darstellung können Sie „Automatisch“, „Hell“ oder „Dunkel“ wählen. „Automatisch“ folgt Ihrem Gerät.

5. Abschließen

Tippen Sie auf den Kreis, wenn die Arbeit erledigt ist. Eine erledigte Aufgabe verlässt die Stapel, ist aber nicht weg: Mehr → Zeitleiste listet alles Erledigte nach Tagen auf, und Sie können eine zu früh abgehakte Aufgabe wieder öffnen.

Wenn Ihre Listen sich verstaubt anfühlen, probieren Sie eine Durchsicht.

Probieren Sie das. Legen Sie „Garten planen“ an. Schieben Sie sie nach „Jetzt“, solange Sie Ideen sammeln. Wenn Sie einen Handwerker um ein Angebot bitten, schieben Sie sie nach „Wartet“ und setzen eine Erinnerung für den Tag, an dem Sie nachhaken wollen. Dieselbe Aufgabe von Anfang bis Ende.

Wo eine Aufgabe liegt und wann Sie sie ansehen wollen

Ein Stapel sagt, was Sie mit einer Aufgabe vorhaben. Ein Datum sagt, wann Sie an sie erinnert werden wollen. DayHand hält beides mit Absicht getrennt.

Die fünf Stapel

Eingang
Was Sie gerade festgehalten und noch nicht eingeordnet haben.
Jetzt
Woran Sie aktiv arbeiten, auch wenn es mehrere Tage dauert.
Als Nächstes
Was Sie anpacken, wenn Sie Platz dafür haben. Es heißt nicht: morgen.
Später
Ideen und Pläne, die Sie behalten wollen und noch nicht anfassen.
Wartet
Arbeit, die eine Antwort, eine Lieferung, eine Entscheidung oder den Beitrag eines anderen braucht, bevor Sie weitermachen können. Anders als „Später“: Hier würden Sie weitermachen, wenn Sie könnten.

Ein Datum verschiebt nie eine Aufgabe. Dass Zeit vergeht, ändert nichts daran, wo sie liegt; Sie entscheiden, wann sie wandert.

Hier eine Aufgabe über eine Woche. Am Montag legen Sie „Präsentation vorbereiten“ an, mit einer Erinnerung für Dienstag und einer Frist am Freitag. Am Dienstag sagt Ihnen die Erinnerung, dass Sie anfangen sollen, also schieben Sie sie nach „Jetzt“. Etwas Dringenderes kommt dazwischen, also geht sie nach „Später“ mit einer neuen Erinnerung für Mittwoch. Am Mittwoch kommt sie zurück nach „Jetzt“. Am Donnerstag schicken Sie einen Entwurf an einen Kollegen und parken sie in „Wartet“. Am Freitag trifft die Rückmeldung ein, Sie werden fertig und haken sie ab. Eine Aufgabe, eine Frist, die sich nie geändert hat, und nie war etwas „überfällig“.

Erinnerungen: sieh dir das noch einmal an

Wählen Sie Erinnere mich… in den Aktionen einer Aufgabe oder legen Sie eine im Editor fest. Erinnerung ändern… wählt einen anderen Tag, und Erinnerung entfernen entfernt sie.

Eine Erinnerung löst um 9 Uhr an dem Tag, den Sie gewählt haben, aus, sofern Mitteilungen für DayHand erlaubt sind. Wenn Sie heute eine nach 9 Uhr setzen, gibt es nichts mehr auszulösen: Die Aufgabe wird als jetzt fällig markiert, und es folgt keine Mitteilung. Die Datumsauswahl sagt das, wenn es so weit ist. (Erinnerungen aus älteren Versionen behalten möglicherweise die Uhrzeit, die sie bekommen haben.)

Tippen Sie auf eine Mitteilung, und DayHand öffnet diese Aufgabe. Sie wegzuwischen ist keine Antwort; die Erinnerung wartet in der App weiter auf Sie. Sie beantworten sie mit Hier lassen (sie liegt im richtigen Stapel, danke), indem Sie die Aufgabe verschieben, sie erledigen oder einen anderen Tag wählen.

Farben, die Flagge und das Badge

  • Oranger Rand: Die Erinnerung kommt innerhalb der nächsten drei Tage.
  • Roter Rand: Die Erinnerung ist heute oder schon vorbei. Er bedeutet „Sie wollten sich das ansehen“, nicht „Sie sind zu spät“.
  • Die Flagge in der App: sammelt jede Aufgabe mit rotem oder orangem Rand aus jedem Stapel. Die Zahl darauf zählt die roten.
  • Das Badge auf dem App-Symbol: zählt Erinnerungen, die eingetroffen sind und die Sie noch nicht beantwortet haben.

Die Flagge und das Badge können also voneinander abweichen, und das ist in Ordnung. Beantworten Sie eine Erinnerung mit „Hier lassen“, und das Badge sinkt, während die Aufgabe ihren roten Rand behält und in der Flagge bleibt, bis Sie das Datum ändern oder löschen.

Fristen: bis dahin fertig

Fügen Sie im Editor eine Frist hinzu, wenn es eine echte Ziellinie gibt: eine Abgabe, eine Verlängerung, eine Lieferung. Um eine neue hinzuzufügen, setzen Sie zuerst eine Erinnerung; das Fristfeld erscheint danach. Wenn Sie die Erinnerung später löschen, bleibt eine Frist, die Sie schon gesetzt haben, sichtbar und bearbeitbar.

Eine Frist löst keine Mitteilung aus und verschiebt nichts. Sie steht einfach an der Aufgabe. Setzen Sie die Erinnerung früh genug, um noch etwas tun zu können.

Keine Mitteilung? Lesen Sie, was Sie prüfen können.

Durchsichten

Öffnen Sie Mehr → Durchsehen und wählen Sie einen Helfer. Jeder stellt eine einzige Frage zu einer einzelnen Aufgabe oder einem einzelnen Projekt, sodass Sie entscheiden, statt eine lange Liste zu überfliegen.

Aufgaben durchsehen

Eingang durchsehen
Wohin gehört das? Schieben Sie neue Aufgaben in den passenden Stapel oder lassen Sie sie liegen, wenn Sie noch nicht so weit sind.
Jetzt durchsehen
Arbeite ich noch aktiv daran? Behalten Sie, was aktiv ist, verschieben Sie, was sich geändert hat, und erledigen Sie, was fertig ist.
Wartend durchsehen
Kann das weitergehen? Behalten Sie, was wirklich blockiert ist, holen Sie zurück, was es nicht ist, oder setzen Sie eine Erinnerung zum Nachhaken.
Als Nächstes und Später durchsehen
Ist das noch relevant? Holen Sie nach vorn, was zählt, und lassen Sie los, was nicht.
Alle Aufgaben durchsehen
„Eingang“, „Jetzt“, „Wartet“, dann „Als Nächstes“ und „Später“, in einem Durchgang. Eine Aufgabe, die Sie während des Durchgangs verschieben, kommt im selben Durchgang nicht wieder.

Der Helfer zeigt die Aufgabe und wie lange sie schon in ihrem Stapel liegt. Lassen Sie sie, wo sie ist, verschieben, bearbeiten, erledigen oder löschen Sie sie. Die Stapel-Tasten bleiben von einer Aufgabe zur nächsten an derselben Stelle, sodass Ihr Daumen sie lernt.

Sie können mittendrin aufhören und später weitermachen. Ihr Stand wird nur auf diesem Gerät gesichert; ein anderes Gerät beginnt seinen eigenen Durchgang. Aufgaben, die in der Zwischenzeit eintreffen, warten auf den nächsten Durchgang.

Eine Durchsicht ist eine Entscheidung, keine Frist. „In Jetzt behalten“ ist eine völlig gute Antwort, auch für eine Aufgabe, die seit einem Monat dort liegt.

Projekte durchsehen

Projekte durchsehen stellt zu jedem Projekt eine Frage: Gibt es einen klaren Weg nach vorn? Sie sehen seine Aufgaben nach Stapel, mit Kategorie und Gruppe.

  • Passt — nächstes Projekt: gut, weiter.
  • Aufgabe hinzufügen: Schreiben Sie den fehlenden Schritt auf, mit diesem Projekt bereits ausgewählt.
  • Diese Aufgaben durchsehen: Gehen Sie die Aufgaben dieses Projekts nacheinander durch.
  • Projekt bearbeiten: Ändern Sie Namen, Kategorie oder Gruppe.

Nach dem Hinzufügen, Bearbeiten oder Durchsehen kehren Sie zum selben Projekt zurück. Der Pfeil oben links führt zum Projekt, das Sie gerade verlassen haben, und das Kreuz beendet die Durchsicht.

Projekte mit unerledigter Arbeit kommen zuerst. Projekte, bei denen nichts mehr zu tun ist, kommen danach, damit Sie sie archivieren können. Archivierte Projekte werden übersprungen, und Aufgaben ohne Projekt erscheinen stattdessen in den Aufgabendurchsichten.

Beim Archivieren eines Projekts, das noch offene Aufgaben hat, werden Sie gebeten, sie zuerst zu erledigen. Archivieren ist für erledigte Arbeit, kein Weg, ein Projekt schlafen zu legen; dafür nutzen Sie „Später“.

Zurückblicken

Mehr → Zeitleiste und der Verlauf eines einzelnen Projekts zeigen, was Sie erledigt haben. Sie sind von den Helfern getrennt, bei denen es um die noch offene Arbeit geht.

Sync

DayHand teilt Ihre Aufgaben über eine Datei in Ihrem eigenen iCloud Drive. Es gibt kein DayHand-Konto und keinen Server. Auf einem einzelnen Gerät brauchen Sie nichts davon.

Das erste Gerät

  1. Stellen Sie sicher, dass iCloud Drive eingeschaltet ist.
  2. Öffnen Sie Mehr → Synchronisierung → Sync-Datei erstellen….
  3. Sichern Sie die Datei in einem iCloud-Drive-Ordner, den Sie wiederfinden.
  4. Geben Sie iCloud einen Moment, sie hochzuladen, bevor Sie das nächste Gerät einrichten.

Jedes weitere Gerät

  1. Melden Sie sich mit demselben Apple-Account an und stellen Sie sicher, dass die Datei geladen ist.
  2. Öffnen Sie Mehr → Synchronisierung → Vorhandene Datei verwenden….
  3. Wählen Sie Mit diesem Gerät zusammenführen, wodurch die Aufgaben auf beiden Seiten erhalten bleiben.
  4. Wählen Sie dieselbe Datei, die Sie auf dem ersten Gerät angelegt haben. Legen Sie keine zweite Datei mit demselben Namen an; zwei Dateien mit einem Namen sind zwei verschiedene Dateien.
  5. Sehen Sie sich Ihre Aufgaben und den Sync-Status auf beiden Geräten an.
Ersetzen ist etwas anderes. „Aufgaben auf diesem Gerät ersetzen“ wirft weg, was auf diesem Gerät ist, und übernimmt stattdessen die Aufgaben der Datei. Wenn Sie die aktuelle Liste vielleicht zurückhaben möchten, machen Sie vorher ein Backup.

DayHand prüft, ob die gewählte Datei wirklich eine DayHand-Datei ist. Eine Tabelle, die JSON-Datei eines anderen oder ein Foto werden abgelehnt, weil der Sync in die Datei schreibt und sie überschreiben würde.

Im Alltag

Jedes Gerät behält seine eigene Kopie, sodass Sie offline arbeiten können. Änderungen treffen sich über die Datei, sobald iCloud sie geliefert und DayHand sie gelesen hat. Das kann dauern, und eine geschlossene App hat es nicht eilig. Erwarten Sie nicht, dass es sofort geht.

Vermeiden Sie es, dieselbe Aufgabe auf zwei Geräten zu bearbeiten, während beide offline sind. Wenn zwei Versionen einer Aufgabe in Konflikt geraten, gewinnt die jüngste Bearbeitung. DayHand fügt zwei Bearbeitungen desselben Titels nicht zusammen.

Wenn die Geräte uneins sind

  1. Sehen Sie auf jedem Gerät unter Mehr → Synchronisierung nach. „Keine Synchronisierung“ bedeutet, dass dort keine Datei verknüpft ist.
  2. Prüfen Sie, dass beide dieselbe Datei am selben Ort nutzen. Derselbe Name genügt nicht.
  3. Prüfen Sie, dass iCloud Drive verbunden ist und die Datei fertig geladen wurde, in Dateien oder im Finder.
  4. Öffnen Sie DayHand auf beiden Geräten und tippen Sie auf Jetzt synchronisieren. Lesen Sie die Zeile unter der Taste.
  5. Wenn Sie die Datei verschoben oder umbenannt haben und ein Gerät sie verloren hat, sichern Sie dieses Gerät per Backup, beenden Sie die alte Verknüpfung und wählen Sie die richtige Datei erneut, mit „Zusammenführen“.

Trennen

Diese Datei nicht mehr verwenden trennt dieses Gerät. Seine Aufgaben bleiben. Wenn Sie nur einmal eine gespeicherte Kopie ansehen möchten, ohne etwas zu verknüpfen, nutzen Sie stattdessen Aus Datei wiederherstellen….

Immer noch nicht gelöst? Sagen Sie es mir und nennen Sie, was der Sync-Status auf jedem Gerät zeigt.

Importe, Exporte und Backups

Ihre Aufgaben gehören Ihnen: hinein, heraus und wieder zurück. Ein Import ist eine einmalige Kopie. DayHand bleibt nicht mit der App verbunden, aus der sie kamen.

Aus Apple Erinnerungen

  1. Öffnen Sie Mehr → Aufgaben → Aus Apple Erinnerungen importieren….
  2. Erlauben Sie den Zugriff auf Erinnerungen. Apple bietet zum Lesen von Listen nur „Vollzugriff“ an. DayHand liest sie und ändert sie nie.
  3. Wählen Sie die Listen, den Stapel, in den die Aufgaben sollen, ein Projekt oder eine Kategorie und ob die Fälligkeitsdaten mitkommen sollen.
  4. Sehen Sie sich die Vorschau an und bestätigen Sie dann.

Ein Fälligkeitsdatum wird zu einer DayHand-Erinnerung um 9 Uhr, nicht zu einer Frist, und das ursprüngliche Datum samt Uhrzeit bleibt in den Notizen. Wiederkehrende Erinnerungen werden übersprungen. Unteraufgaben, Tags, Anhänge und Regeln intelligenter Listen werden nicht übernommen. Notizen, Links, Orte und Prioritäten kommen, wo es sie gibt, als Text mit.

Zuerst wird ein Backup angelegt. Importieren Sie dieselben Listen auf demselben Gerät noch einmal, werden schon importierte Aufgaben übersprungen, auch die, die Sie gelöscht haben. Auf einem anderen Gerät oder nach dem Zurücksetzen Ihres Accounts können Dubletten entstehen.

Aus Todoist

  1. Exportieren Sie in Todoist Ihre Projekte als CSV-Dateien.
  2. Öffnen Sie Mehr → Aufgaben → Aus Todoist importieren… und wählen Sie eine oder mehrere dieser Dateien.
  3. Wählen Sie für jede Datei Stapel, Projekt und Kategorie und sehen Sie sich die Datumsoptionen an.
  4. Lesen Sie die Vorschau und eventuelle Warnungen, dann importieren Sie.

Der Projektexport von Todoist enthält keine erledigten Aufgaben. Daten, die DayHand erkennt, werden zu Erinnerungen um 9 Uhr; Fristen bleiben Fristen. Beschreibungen, Kommentare und die übrigen lesbaren Details gehen in die Notizen. Unteraufgaben werden eigene Aufgaben, mit vermerktem übergeordnetem Element und Abschnitt. Anhänge werden nicht heruntergeladen. Wiederkehrende Zeitpläne werden nicht neu angelegt. Ein Datum, das DayHand nicht versteht, wird für Sie markiert; wenn Sie die Aufgabe trotzdem importieren, bleibt der Originaltext des Datums in den Notizen.

Zuerst wird ein Backup angelegt. Wenn Sie eine unveränderte Datei unter demselben Namen importieren, werden die schon importierten Zeilen übersprungen. Bearbeiten oder benennen Sie den Export um, können Dubletten entstehen.

Achten Sie auf Ihre Meldungen. Apple Erinnerungen und Todoist senden weiter ihre eigenen Mitteilungen, und eine zukünftige Erinnerung, die Sie importieren, meldet sich auch von DayHand aus. Entscheiden Sie, welche App Sie nerven darf.

DayHand-CSV

Mehr → Aufgaben → Als CSV exportieren… speichert eine übertragbare Kopie. Aus CSV importieren… bietet Zu vorhandenen Aufgaben hinzufügen, wodurch eine DayHand-CSV in Ihre Arbeit eingefügt wird, oder Alle Aufgaben ersetzen, wodurch zuerst die aktuellen Aufgaben gelöscht werden. Überlegen Sie es sich zweimal, bevor Sie Letzteres wählen.

Für Todoist-Dateien nutzen Sie den Todoist-Import. CSV-Dateien aus anderen Apps passen nicht zum Format von DayHand. Wenn Sie selbst eine Datei vorbereiten möchten, exportieren Sie erst ein paar Aufgaben und übernehmen Sie das Layout.

Backups

Tippen Sie unter Mehr → Sicherungen vor allem Größeren auf Jetzt sichern. DayHand legt an Tagen, an denen Sie die App öffnen, auch selbst welche an, in einigen rotierenden Plätzen: gestern, vorgestern und etwa vor einer Woche. Sie sind ein Sicherheitsnetz, kein Archiv. Ein zweites manuelles Backup am selben Tag ersetzt das erste.

Um eine Kopie an einem Ort Ihrer Wahl aufzubewahren, nutzen Sie die Aktion Teilen eines Backups. Auf einem Mac klicken Sie ein Backup mit der rechten Maustaste an für Wiederherstellen, Teilen und Löschen. Auf einem iPhone oder iPad halten Sie es gedrückt. Wischen geht auch.

Wiederherstellen

  1. Wenn Sie die aktuellen Aufgaben vielleicht zurückhaben möchten, sichern oder exportieren Sie sie zuerst.
  2. Tippen Sie in der Liste auf ein Backup oder wählen Sie Aus Datei wiederherstellen… und wählen Sie eine beliebige DayHand-Datei.
  3. Lesen Sie die beiden Zahlen in der Bestätigung: die Aufgaben hier und die Aufgaben in der Datei. Das Wiederherstellen ersetzt die aktuellen Aufgaben und bringt auch die Kategorien und Projekte zurück.
  4. Bestätigen Sie nur, wenn dies die Kopie ist, die Sie wollen.

Aus Datei wiederherstellen… liest die Datei nur. Sie wird nicht für den Sync verknüpft. Wenn Sie synchronisieren, bleibt das, wie es war; was Sie wiederherstellen, wandert also auch auf Ihre anderen Geräte. Um eine Kopie für sich allein anzusehen, beenden Sie zuerst den Sync.

Für eine dauerhafte Verknüpfung mit einer geteilten Datei siehe Sync.

Gratis und Bezahlt

Der Plan ist eine kostenlose App mit einem einzigen Kauf, der den Rest freischaltet. Kein Abo.

Wo wir stehen. Dies ist eine Beta, und alles ist freigeschaltet. Der Kauf, die 30-tägige Testphase und das Wiederherstellen von Käufen sind noch nicht gebaut. Was folgt, ist der Plan, damit Sie wissen, was Sie erwartet. Mit einem Testschalter in der Beta probiere ich die Grenzen auf meinen eigenen Geräten aus.

Gratis

Unbegrenzt viele Aufgaben, Kategorien und Gruppen, bis zu drei aktive Projekte und die letzten 30 Tage erledigter Aufgaben. Die Durchsichten, Notizen, Erinnerungen, Fristen, der Sync, Importe, Exporte und Backups sind alle enthalten. Ich will die nützlichen Teile nicht hinter einer Mauer.

Die Freischaltung

Ein Kauf, einmalig: unbegrenzt viele aktive Projekte und Ihr voller Verlauf erledigter Aufgaben, auf Ihrem iPhone, iPad und Mac, mit demselben Apple-Account. Den Preis trage ich hier ein, sobald es ihn gibt.

An der Grenze

Archivierte Projekte zählen nicht mit, das Archivieren eines fertigen Projekts macht also einen Platz frei, und das Wiederherstellen eines archivierten nimmt einen Platz. Eine Aufgabe festzuhalten wird nie blockiert. Ein Projekt, das Sie schon haben, bleibt les- und bearbeitbar, auch wenn ein Import Sie über drei bringt.

Erledigte Aufgaben, die älter als 30 Tage sind, werden nur in der Zeitleiste ausgeblendet. Die Suche findet sie weiterhin, und sie bleiben in Ihren Backups und CSV-Exporten. Nie wird etwas gelöscht, weil Sie nicht bezahlt haben.

Die Testphase

Ich plane eine 30-tägige Testphase, die Sie selbst starten. Wenn sie endet, kehrt die App zur kostenlosen Version zurück. Keine Kosten, und nichts geschieht automatisch. Sie ist noch nicht verfügbar, ebenso wenig das Wiederherstellen von Käufen. Ich erkläre beides hier, sobald sie erscheinen.

Fehlerbehebung

Sehen Sie sich unten die üblichen Verdächtigen an. Wenn es keiner davon ist, schreiben Sie mir, dann versuche ich herauszufinden, was passiert ist.

Ich finde meine Aufgaben nicht

Löschen Sie zuerst die Suche, die Kategorie- und Projektfilter und die Flagge. Schauen Sie dann in die anderen Stapel und in die Zeitleiste; eine abgehakte Aufgabe finden Sie dort. Wenn ein zweites Gerät etwas anderes anzeigt, lesen Sie die Sync-Checkliste, bevor Sie etwas ersetzen oder wiederherstellen.

Wenn Sie von einer selbst gebauten Mac-Version zur TestFlight-Version gewechselt sind, speichert die App ihre Daten an einem anderen Ort und startet deshalb leer. Es ist nichts verloren. Wenn Sie eine iCloud-Sync-Datei genutzt haben, wählen Sie Vorhandene Datei verwenden und zeigen Sie auf dieselbe Datei, mit Zusammenführen.

Eine Erinnerung blieb stumm

  • Sind Mitteilungen für DayHand in den Systemeinstellungen erlaubt? Hält ein Fokus sie zurück?
  • Erinnerungen werden an ihrem Tag um 9 Uhr ausgelöst. Für eine Erinnerung für heute, die nach 9 Uhr gesetzt wurde, kommt keine Mitteilung mehr.
  • Eine erledigte Aufgabe oder eine gelöschte Erinnerung meldet sich nicht. Eine für diesen Tag bereits beantwortete Erinnerung hat dazu auch keinen Grund.
  • Öffnen Sie DayHand. Beim Start aktualisiert die App ihren Zeitplan, was vor allem nach Änderungen auf einem anderen Gerät wichtig ist.

Wenn die Flagge und das Badge auf dem Symbol unterschiedliche Zahlen zeigen, ist das Absicht. Hier steht, warum.

Meine importierten Aufgaben sehen anders aus

Jeder Import hat Grenzen bei Terminen, wiederkehrenden Aufgaben und zusätzlichen Details. Die Import-Anleitung listet sie auf. Schauen Sie zuerst in die Notizen der Aufgabe: Was DayHand nicht zuordnen konnte, steht meist dort als Text.

Kontakt

DayHand wird von einer einzelnen Person gemacht, es gibt also kein Ticketsystem. Nutzen Sie während der Beta Beta-Feedback senden in TestFlight. Sie können auch ein Issue auf GitHub eröffnen, für einen Fehler, eine Frage oder eine Idee. Dafür brauchen Sie ein GitHub-Konto; zum Lesen dieser Seiten nicht.

Es hilft sehr, wenn Sie mir Folgendes mitteilen:

  • Ihr Gerät, dessen Systemversion sowie die Version und den Build von DayHand;
  • was Sie getan haben, was Sie erwartet haben und was geschehen ist;
  • die genaue Meldung auf dem Bildschirm, falls es eine gab;
  • bei Sync-Problemen: welche Geräte betroffen sind und was der Sync-Status auf jedem anzeigt.
GitHub-Issues sind öffentlich. Schwärzen Sie private Aufgabentitel in Screenshots. Hängen Sie weder Ihre Aufgabendatei noch ein Backup an, und keine Passwörter oder persönlichen Angaben. Ein kleines erfundenes Beispiel, das dasselbe Problem zeigt, ist ohnehin besser.

Bevor Sie schreiben, können Sie die vorhandenen Meldungen durchsehen; vielleicht ist jemand schon darauf gestoßen.
